# 🏛️ Gram Panchayat Agriculture AI Kiosk Terminal

An interactive, high-fidelity rural kiosk terminal prototype designed for **Raiyata Seva Kendras** to empower non-literate and literate farmers with instant subsidy diagnostics, multi-language voice navigation, and physical action roadmaps.

---

## 🚀 Core Features

* **🎙️ Bhashini AI Voice Integration:** Single-tap voice assistance with auto-detect across regional dialects (Kannada, Hindi, Telugu, Tamil, Marathi, Punjabi) for universal accessibility.
* **⚠️ Predictive Subsidy Diagnostics:** Instantly surfaces stalled Direct Benefit Transfer (DBT) applications caused by joint-land (Pahani/RTC) name mismatches or unlinked bank accounts.
* **📸 Hardware Abstraction Layer (HAL) Simulation:** Secure on-spot hardware stream simulation for biometric thumbprint verification and physical paper slip scanning.
* **🟢 3-Step Physical Action Roadmap:** Breaks down complex administrative roadblocks into simple, non-literate-friendly visual and audio guidance steps.

---

## 🛠️ Tech Stack & Design

* **Framework:** Next.js / React (v0 generated architecture)
* **Styling:** Tailwind CSS (High-contrast forest green and yellow theme optimized for 15.6-inch touchscreen kiosks)
* **Deployment:** Hosted live via Vercel with automated GitHub version control
